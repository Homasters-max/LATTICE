## 6. Риски согласованности

- **Обратная правка 10-kernel.** Если Q2 (`extends` только `id@n`) принято — KR-09 (`domains/10-kernel.md:250`) не
  упоминает версию родителя; файл уже пройден (D02) → правка сразу (одна строка) или строка N с пометкой в журнале.
- **X-52 повтор.** ADR-29 не значится в «Файлы» реестра со значением `13-rules` — тот же дефект, что у ADR-2, -17.
  При закрытии: `ledger.mjs set ADR-29 ... --files "13-rules,22-run,23-bench,14-trust"` — проверить перед `set`.
- **01-first-run.md, 05-slices.md не пройдены.** Терминология «находок hard» (И-9) — не править напрямую, а две
  строки N этим файлам (их подхватят будущие брифы).
- **Владение не смешивать.** `std/ctx`/`Deps`(`view`) — у 22-run; 13-rules у И-7 только объявляет `reads`/`writes`
  и `compatible`, ссылается на `std/ctx@1` и на `Deps` текстом, не определяет заново.
- **21-compose не пройден.** Слияние `max-members`→`count` (И-5) — только правило в 13-rules; текст `max_members`
  самого 21-compose (граница обучения) не трогать здесь — это D09.
- **Глоссарий сместился.** Фрагмент ссылается на `02-glossary.md:68` (T44); сейчас `:77` — адреса старых фрагментов
  не совпадают построчно с текущим файлом; при записи «Где» — свежий `grep -n`, не адрес фрагмента.
- **`grain-unique`/ADR-27.** Текущее описание примитива (`:38`) не называет область (пространство автора,
  `grain_scope: store`) — после ADR-27 (внесён в 11-identity-grain) это расхождение уже фиксирует N-25.
- **`renames.md`.** `grep -n` по старым именам (`grounding`, `import()`, `lattice import`, `--mode`) в
  `13-rules.md` — совпадений нет, правок замены не требуется.
