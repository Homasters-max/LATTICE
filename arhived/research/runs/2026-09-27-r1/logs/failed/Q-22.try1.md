# Пакет Q-22 · LG-02 · Текущее состояние как вычисляемая проекция журнала — как строить, пересобирать и версионировать индекс?

## Контекст в дизайне
- `design/domains/12-ledger.md:31-49#77cbb1` — раздел «3. Индекс — вычисляемое состояние»: индекс не хранит ничего сверх
  журнала, разделы (`revisions`, `latest`, `byType`, `grain`, `aliases`, `facts`, `consumers`, `trust`, `snapshots`),
  вычисляемые атрибуты не пишутся в журнал.
- `design/domains/12-ledger.md:50-53#b5c7a9` — «4. Пересборка детерминирована»: `rebuild()` дважды на одном журнале →
  побайтно одинаковый индекс; регрессионная проверка системы.
- `design/domains/12-ledger.md:55-65#a81d31` — «5. Порт хранилища»: интерфейс `Store` с `append`, `scan`, `lock` и
  необязательными `saveIndex?`/`loadIndex?` (кэш индекса).
- `design/domains/12-ledger.md:84-87#a7a60d` — Инварианты: журнал только растёт; `rebuild(ledger) == index`; в журнале нет
  строк, не прошедших `hard`.
- `design/domains/12-ledger.md:94#dd966b` — сама строка решения LG-02.
- `design/domains/12-ledger.md:109-110#6448ce` — вопрос для grilling: кэш индекса на диске сразу или пересборка при
  старте — рекомендация «пересборка, пока журнал < 50 МБ».
- `design/domains/30-adapters.md:40-44#b55304` — адаптер `store-jsonl`: `.lattice/index.json` — кэш; `lattice rebuild
  [--check]` — пересборка индекса, `--check` сравнивает побайтно.
- `design/domains/14-trust.md:73-77#7fb25b` — «6. Чем доверие не является»: доверие не хранится, пересчитывается в
  индексе при каждом новом утверждении по затронутой цели (доверие — один из разделов индекса).
- `design/domains/14-trust.md:113-115#ea1d87` — устаревание не по времени: статус snapshot'а решает изменение версий
  членов, а не срок давности.
- `design/domains/11-identity-grain.md:83-85#4ef5c9` — слияние (алиасы): индекс хранит карту алиасов, цепочки сжимаются,
  циклы запрещены правилом `acyclic`.
