## Q-02. Минимальный фиксированный заголовок и открытое тело без обязательной схемы — как не получить неуправляемые данные?

- **Место в дизайне:** KR-02 `design/domains/10-kernel.md:161#a66492` — «заголовок фиксирован и минимален; тело открыто;
  ограничивают правила»; поля заголовка и «`body` — любой JSON» `design/domains/10-kernel.md:23-30#6b224e`; `schema` —
  добровольная форма тела `design/domains/10-kernel.md:100#289d2f`; принцип P1 `design/00-vision.md:64#41261b`. Правила: примитив
  `schema` и его подмножество `design/domains/13-rules.md:33#897251`; набор примитивов растёт только с версией ядра
  `design/domains/13-rules.md:48#70e0ea`; где проверяются правила `design/domains/13-rules.md:65-72#8090b0`; RL-02
  `design/domains/13-rules.md:87#34f039`; правило вне примитивов — только `soft` `design/domains/13-rules.md:97-98#579420`. Пропущено
  сборщиком (R-1): публикация версии типа проверяет только зерно и наследование `design/domains/13-rules.md:70#baf786`;
  старые ревизии валидны по своей версии типа, перевод — по мере правки `design/domains/11-identity-grain.md:91-96#6106fd`;
  владелец `std` — сопровождающий LATTICE `design/domains/10-kernel.md:130#5d12f3`.
- **Уже исследовали:** Q-01 (`research/2026-09-27-universal-record.md`) — C-1: стабильный заголовок + открытое тело —
  рабочий приём, заголовок расширять только версией формата ядра; C-2: схема `hard` обязательна для типов `core`,
  `std` и импортируемых, добровольна для локальных. Здесь не повторяются — ниже только новое: эволюция версий,
  закрытость схемы, условие устойчивости ядра.
- **Цена отката:** высокая (правило; данные без него уже в журнале придётся проверять задним числом) → L2.
- **Глубина:** L0 (5 выдач сборщика) → L1 (8 разделов 5 карточек: ANT-098 §Симптом, §Почему вредно, §Чем заменить;
  PAT-159 §Решение, §Trade-offs; PAT-193 §Решение; PAT-013 §Решение; PAT-132 §Решение, §Когда не применять) → L2
  (`related` ANT-098 → PAT-159 прочитан; ANT-097, ANT-090 — «единая модель на всё», закрыто в Q-01 C-3; карта
  `maps/map-architecture.md:241#ad41a7` — PAT-197 «эвристики семантического моделирования данных» по описанию о разбиении
  данных, не об управлении схемой — не открыт). DEC-041 (мнимый контракт) не взят: о связности модулей, к форме
  записи не прикладывается без натяжки.
- **Бюджет:** запросы 1 + 4 узких — сборщик; куратор — 1 повтор F5 вне лимита (у сборщика его не было, R-3) · разделы 8 из 5 — превышение: ANT-098 и PAT-132 —
  по три раздела ради ГРАНИЦ (E-9, E-10) и потому, что две карточки уже прочитаны в Q-01 и нужны с новой стороны.
- **Статус:** отвечен.
