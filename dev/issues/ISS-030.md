# ISS-030 — Git Bash превращает аргумент ref:путь в путь Windows

MSYS переписывает аргументы, похожие на POSIX-путь, до передачи программе — `git show origin/main:<путь>` ломается.

## Симптом

`fatal: ambiguous argument 'origin\main;.warrant\local\rules\session-start.json': unknown revision or path not in the working tree.`

## Причина

Преобразование путей MSYS2 в Git Bash на Windows.

## Обход

RUL-055: `MSYS_NO_PATHCONV=1` (или `export MSYS_NO_PATHCONV=1`) перед такой командой.
