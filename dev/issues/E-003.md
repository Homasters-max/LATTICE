# Не больше 20 субагентов; 429 обрывает всех

**Симптом.** Харнесс держит ≤ 20 одновременных агентов (`CLAUDE_CODE_MAX_CONCURRENT_SUBAGENTS`), кураторы — в том же
лимите; HTTP 429 обрывает все сразу. **Обход.** Пул ≤ 20 всех ролей; после 429 — возобновлять через SendMessage
(«продолжи с места остановки»), не перезапускать. **Закрытие.** При следующем пакетном прогоне.
