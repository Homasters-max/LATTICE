# ISS-003 — Парсер junit не видел testcase вне testsuite (node:test)

Тесты `test()` вне `describe()` не учитывались в evidence; только верхнеуровневые — `INCONCLUSIVE`.

## Симптом

«no <testsuite> found» при наборе из одних `test()`; в смешанном наборе число тестов занижено.

## Причина

Parser `junit` суммировал только атрибуты `<testsuite>`.

## Обход

RUL-008: каждый тест внутри `describe()`.

Исправлено в v0.8.1 (`warrant/ADR-0042`); проверка в LATTICE — impl-PR kernel-format (`gh/5#issuecomment-5865888855`).
