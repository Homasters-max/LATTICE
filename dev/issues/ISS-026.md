# ISS-026 — Задачи проверки Change нельзя отметить, archive их не требует

Задачи `tasks.md` о `verify` и локальном `warrant ci` выполняются после `run finish`, когда `tasks.md` вне `write_scope`, — и Change уходит в архив с неотмеченными задачами.

## Симптом

`openspec/changes/archive/2026-09-28-pin-v0-8-1/tasks.md`: 3.1, 3.2 — `- [ ]`, хотя выполнены (git/4656830, тело PR #6).

## Причина

`tasks.md` правится только в Run implement; проверки идут после коммита `VERIFYING`; `archive` отметок не проверяет.

## Обход

Задачи проверки не заводить в `tasks.md` — их держат gates WARRANT (`verify`, `warrant ci`); результат — в теле PR.

## Закрытие

- [ ] WARRANT: `archive` (или gate `VERIFYING->MERGED`) требует отметок всех задач, либо задачи проверки — вне `tasks.md` по шаблону · cmd
- [ ] до исправления — правило в процедуре Change ([rules/process.md](../rules/process.md)) · human
