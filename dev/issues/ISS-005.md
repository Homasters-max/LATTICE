# ISS-005 — warrant-reviewer недоступен в сессии, где выполнен sync

Claude Code читает `.claude/agents/` и hooks при старте сессии; после `sync` агент не находился, подсказки не было.

## Симптом

`Agent type 'warrant-reviewer' not found`.

## Причина

Агенты и hooks читаются при старте сессии.

## Обход

Новая сессия после `sync` — шаг человека (pin-v0-8-1#8).

## Закрытие

v0.8.1 — `FRONTEND_RESTART_REQUIRED`; принято в pin-v0-8-1 (`gh/5#issuecomment-5865888855`), проверено `git/ae75067`.
