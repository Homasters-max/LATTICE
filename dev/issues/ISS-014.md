# ISS-014 — Edit/Write превращают \uXXXX в символы

Инструменты Claude Code раскрывают литеральные escape-последовательности в символы.

## Симптом

Литеральный escape `\u0041` в тексте становится символом; сработало при записи самой этой проблемы (dev-state).

## Причина

Поведение инструментов Edit/Write.

## Обход

RUL-003: литеральный escape — perl с `\x5c`.

## Закрытие

- [ ] Edit/Write сохраняют литеральный \uXXXX на файле-образце · cmd

Проверка на образце при каждом пересмотре.
