# ISS-015 — Git Bash — команда длиннее ~7 тыс. символов даёт unexpected EOF

Длинный heredoc через Bash-инструмент на Windows искажается до shell.

## Симптом

`unexpected EOF while looking for matching` на сообщении коммита, теле PR, JSON.

## Причина

Передача длинной многострочной команды Bash-инструментом на Windows.

## Обход

RUL-004: файлом (`git commit -F`, `gh pr create --body-file`, `--file`); соблюдено в pin-v0-8-1 (`RPT-001`).
