# ISS-006 — run submit с длинным envelope через heredoc ломается

Envelope review ~16 КБ через heredoc искажается до shell; ошибка не показывала, что получено.

## Симптом

`SKILL_RESULT_INVALID … must have required property 'skill'`; `unexpected EOF while looking for matching`.

## Причина

Передача длинной многострочной команды через Bash-инструмент на Windows (ISS-015).

## Обход

RUL-005: envelope файлом вне репозитория, `warrant run submit --file`, сначала `--dry-run`. В pin-v0-8-1 субагент с
`warrant-reviewer.md` 0.8.0 сдал heredoc'ом ~6 КБ — прошло, но правило до него не дошло (ISS-023, `RPT-001`).

## Закрытие

v0.8.1 (`warrant/ADR-0042`) — сдача файлом в инструкции `warrant-reviewer`; проверка — review 2 kernel-format.
