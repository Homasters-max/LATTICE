# ISS-016 — Не больше 20 субагентов, HTTP 429 обрывает всех

Харнесс держит ≤ 20 одновременных агентов, кураторы — в том же лимите; 429 обрывает все сразу.

## Симптом

Прогон r1: запрошено 30 агентов — не вышло; 429 оборвал все 20.

## Причина

`CLAUDE_CODE_MAX_CONCURRENT_SUBAGENTS`, лимит сессии.

## Обход

Пул ≤ 20 всех ролей; после 429 — возобновлять через SendMessage, не перезапускать.

При следующем пакетном прогоне.
