# ISS-019 — Подсказка «start a Run first» на каждую правку вне Change

Правка dev/ без Run — норма процесса, но guard каждый раз советует начать Run; `AGENTS.md` называет это `deny`.

## Симптом

22 подсказки `start a Run first: warrant run start <change> --operation specify|implement` за сессию pin-v0-8-1.

## Причина

`decide.ts:174` — allow с hint для всех путей вне denylist; текст правила `process` говорит «правка без Run — deny».

## Обход

Игнорировать для dev/**, `CLAUDE.md`, `.gitignore`.

## Закрытие

WARRANT: hint только там, где путь относится к Change; текст `process` — по фактическому поведению.
