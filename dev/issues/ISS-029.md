# ISS-029 — Правка функции с регулярными выражениями кусками ломается раз за разом

Серия маленьких патчей Python-скрипта через heredoc и Edit по кускам: экранирование `\n` и кавычек сбивается, форма
данных расходится с местами использования.

## Симптом

`SyntaxError: unterminated string literal`, `String to replace not found in file`, затем `ValueError: too many values to
unpack (expected 2)` — 5 неудач подряд в `scripts/dev/session-digest.py` (SES-4a6aa6ee, ≈14 вызовов).

## Причина

Двойное экранирование bash → python → regex при патче строки внутри строки; правка по кускам без чтения функции целиком.
Во время серии не было строки статуса (ISS-027, RUL-051).

## Обход

RUL-056: Read функции целиком, одна замена блока; после смены формы данных — `grep` всех мест использования.
