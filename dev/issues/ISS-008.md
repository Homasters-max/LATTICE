# ISS-008 — warrant id не резервирует номер

Номер вычисляется по файлам: повторные вызовы до записи дают один и тот же ID.

## Симптом

8 вызовов `warrant id REQ KR` → 8 раз `REQ-KR-001`.

## Причина

Нет резервирования и счёта черновиков.

## Обход

RUL-006: нумеровать подряд, проверит `ids-valid`.
