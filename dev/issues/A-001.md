# perl -pe не находит кириллицу в шаблоне

**Симптом.** `perl -i -pe 's/<кириллица>/…/'` молча не заменяет (исходник скрипта читается как байты), с `-CSD` без
`-Mutf8` — тоже; один раз — `Unrecognized character \xD0`. **Обход.** R-L0-09: правка с кириллицей — Edit; perl —
только ASCII-шаблоны или `perl -Mutf8 -CSD`. **Закрытие.** По `close_when`.
