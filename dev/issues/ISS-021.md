# ISS-021 — У warrant нет компактного вывода — JSON разбирается вручную

Чтобы достать поле из ответа `warrant`, агент каждый раз пишет `node -e 'JSON.parse…'`.

## Симптом

14 ручных разборов JSON за сессию pin-v0-8-1; в конвейере `… | j && …` код выхода взят от `node` — второй переход
запустился после отказа первого.

## Причина

Вывод — всегда полный JSON; фильтра нет.

## Обход

Один помощник разбора на сессию; код выхода проверять у `warrant`, не у конвейера.
