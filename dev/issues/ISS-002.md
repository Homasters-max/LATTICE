# ISS-002 — Guard запрещал любую команду node

Префикс guard по умолчанию был первым словом команды check — запрещался весь `node …`.

## Симптом

`` `node -e …` runs check tests-passed directly (prefix `node` …): it runs only through warrant check ``.

## Причина

`guardedChecks` без `execution.guard_prefixes` брал `defaultPrefix` — первое слово.

## Обход

Не нужен с 0.8.1.
