# ISS-020 — Guard Bash запрещает команду check вне репозитория, а Write туда пропускает

Проба `node --test` в копии дерева во временном каталоге получила `deny`, хотя запись файлов туда guard пропустил.

## Симптом

`runs check tests-passed directly … it runs only through warrant check` для команды в worktree вне проекта.

## Причина

Guard Bash матчит префикс команды без учёта cwd; для Write проверяет путь относительно проекта.

## Обход

Пробы check — через `warrant check` в копии дерева.

## Закрытие

WARRANT: единое правило области для Bash и Write.
