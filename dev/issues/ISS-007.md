# ISS-007 — Run review запрещает команды только для чтения

Пока идёт Run review, guard отклоняет любую команду, кроме `warrant run submit`, даже `cd` и `warrant status`.

## Симптом

`a review Run runs only warrant run submit`.

## Причина

Guard Run `review` (`warrant/ADR-0036`).

## Обход

RUL-005: состояние смотреть до `run start`.

## Закрытие

`warrant/BL-81`.
