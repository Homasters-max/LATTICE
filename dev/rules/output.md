# output — Вывод агента человеку

Три шаблона — старт, остановка, готово: человек по одной таблице видит, где мы, что сделано, что от него нужно и что
дальше.

## Область

Сообщения основной сессии человеку. Субагенты отвечают основной сессии в своём формате. Для всех проектов — PRP-001 P-10.

## Процедуры

**▶️ Старт** — первое сообщение сессии (протокол README):

```
▶️ Старт · <дата>
| Фокус     | state → <дорожка> → <work> → <шаг или этап Change, задача x/y> |
| WARRANT   | <change>: <change_state>, next <operation> · или «нет активного Change» |
| Сигналы   | просрочки review_by · switch · правила (конфликты, >7) · «нет» |
| Очередь   | шаги человека и WAIT · «пусто» |
| Сессии    | неразобранные: N (SES-…) · «все разобраны» |
| Начинаю   | <следующий шаг> |
```

**⏸️ Остановка** — нужен человек:

```
⏸️ Нужно твоё действие · <work или change> · шаг N из M
| Цепочка  | IDEA-… → <work> → <шаг / этап Change · задача x/y> |
| Сделано  | 1–2 строки + ссылки (PR, EVID, коммит) |
| Проблемы | ⚠ ISS-… сработала · 🆕 ISS-… · «нет» |
| Дальше   | что сделаю после твоего действия |

❗ Выполнить — <что>:
<одна команда>
```

**✅ Готово** — работа без Change или Change закрыты:

```
✅ <work или change> завершена
| Итог      | 3–5 пунктов: что изменилось |
| Ссылки    | PR, коммиты, EVID |
| Проверено | чем и что показало |
| Проблемы  | найдено / закрыто / сработало |
| Разбор    | SES-… · RPT-… или «ждёт аналитика» |
| Следующий | следующая работа по focus |
```

## Проверка

Разбор сессии (`RPT`): есть ли блок на каждой остановке и первым сообщением; «шаг N из M» совпадает с `warrant status`
и `tasks.md`.
