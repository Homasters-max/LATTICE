## Решения

| id | решение | ref |
|---|---|---|
| D-1 | причина — агент копирует форму текста из контекста: свежий Sonnet без контекста — 0 переносов, после чтения одного перенесённого документа — 12, с перенесённым промптом — 27; на сложном документе после чистки — 0 | gh/12 |
| D-2 | правило в общих инструкциях агентов и хук на запись не нужны: в чистом контексте агент не переносит; агент изредка ставит метки `**X:**` подряд без пустой строки — их молча исправляет `--fix` | gh/12 |
| D-3 | структуру определяет парсер Prettier, меняются только переводы строк; файл пишется только при эквивалентном разборе; `.txt` не склеивается — там перевод строки часть содержания | gh/13 |
| D-4 | адреса строк не держим: ссылка — на id элемента, раздел или файл (RUL-038); заметки базы — `kb/ID#Раздел` | gh/14 |
| D-5 | шаблон — сам итоговый файл в минимальном виде (frontmatter, заголовок, абзац-суть, обязательные разделы), заглушка — одна строка `<…>`, без инструкций в HTML-комментариях; как заполнять — один раз в описании типа | wrap-cleanup |
