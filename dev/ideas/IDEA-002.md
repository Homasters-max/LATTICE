# IDEA-002 — Модель dev/ на объектах LATTICE, отчёты отладки, стандарты разработки

Стандартные разделы узлов, классификация папок и единые id по идеям LATTICE, точка входа и сквозная цепочка, отчёты
отладки сессий, общие правила разработки с переопределением ниже.

## Суть

Запрос maintainer'а 2026-09-28 (чат этой работы; решение фиксируется комментарием в PR `dev-model`):
- стандартизировать разделы `tracks/*` и их наполнение;
- логическая классификация папок и файлов, обоснованный классификатор id, сразу на идеях LATTICE;
- точка входа (идея, тикет) и прозрачная цепочка до результата;
- при отладке LATTICE и WARRANT — отчёт: сбои, чего не хватает, что улучшить системно; первый — по сессии pin-v0-8-1;
- папка общих правил (разработка, качество кода), переопределяемых ниже; ссылки узлов на проблемы и правила.

Уточнения того же дня: разбор сессий — не рабочим агентом, а отдельным субагентом по транскрипту (id сессии уже есть в
имени транскрипта, хук не нужен); `focus` ≠ приоритет; история неизменна; `done_when` проверяемый; просрочка — сигнал;
выход из тупика; критерий — dev/ остаётся маленьким слоем координации.

## Исход

Работа `dev-model` (модель, миграция, стандарты, `RPT-001`), затем `session-audit` (навык и сжатие транскрипта).
