# PRP-001 — Контекст разработки подключённого проекта — предложение WARRANT

Штатная часть для всех подключённых проектов: правила по операции с происхождением и сроком, их доставка и
доказательство, канал старта сессии, очередь человека, разбор сессий; вход grilling нарезки фазы 5 WARRANT.

## Контекст

`warrant/ADR-0032` решил контекст разработки для самого WARRANT; в продукт фазы 4 вошли hooks guard и `AGENTS.md` из
правил, SessionStart и слой контекста — нет. LATTICE держал состояние, ловушки и правила в auto-memory — вне
репозитория, без проверки в PR — и заменил её dev/ ([README](../README.md)). Граница: разрешено, доказано, доставка
нормы → WARRANT; смысл, связи, история, обучение → LATTICE (`docs/handoff/lattice.md` WARRANT: «WARRANT на LATTICE»).
Над Change WARRANT новых понятий не получает: дорожки, фокус, журнал, проблемы как знание остаются в LATTICE.
