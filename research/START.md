## Как вести вопрос — кратко (подробно — навык)

1. Широкий поиск без фильтра: `node ~/.claude/skills/kb-search/scripts/kb-search.mjs --kb "вопрос своими словами"`.
2. Грани: `... --kb "грань" --profile design --k 5 --brief`; строка `# !` → повтор без фильтра.
3. Разделы: `... --kb --section ID "Решение|Когда не применять"` — строки уже с `путь:строка`.
4. Отчёт → `check-refs --stamp` → `--used` → ✓ в списке → `kb-findings.md` → **этот файл** → стоп.
