## Домены (`--domains`)

У заметок нет поля `domain` (или `tags`) — фильтр по доменам в этом проекте не работает.

## Составные фильтры

- `--domains auto` — домены берутся из бесплатной BM25-выдачи этого же вопроса (топ-10); можно дописать свои: `auto,security`.
- `--not-types T,T` / `--not-domains D,D` — исключения; заметка уходит, только если **все** её домены исключены.
- `--profile <имя>` — именованный набор из `.kb-search.json` (`profiles`); явные флаги перекрывают поле профиля; `--profile none` — без профиля.

Профилей в `.kb-search.json` нет.

Что лежит в каждом домене (характерные слова, опорные заметки, типичные вопросы) — `filter-index.md` рядом.

Пример: `kb-search.mjs "вопрос" --domains auto --not-types term`. Первый поиск по новой теме — без фильтра;
`# ! фильтр, вероятно, отсёк ответ` или «под фильтром ответа, вероятно, нет» — повторить без фильтра.
