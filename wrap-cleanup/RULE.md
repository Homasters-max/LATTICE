# Правило переносов строк в Markdown

Перевод строки — только на границе структуры. Внутри абзаца и пункта списка переводов строки нет, какой бы длинной ни была строка.

- Абзац — одна строка. Между абзацами — пустая строка.
- Пункт списка — одна строка. Вложенный пункт — своя строка с отступом.
- Заголовок, строка таблицы, абзац цитаты `>` — одна строка.
- Код, frontmatter, HTML — не трогать.
- Строка, которая должна быть видна отдельно, — отдельный абзац или пункт списка (одиночный перевод строки при отображении склеится).
- Длинный абзац по ширине не переносить; труден для чтения — разделить по смыслу на абзацы или список.
- Адрес места — `файл.md#раздел` или id, не номер строки.

Формулировка для инструкций агента (`CLAUDE.md`, `AGENTS.md`, промпты): «Markdown: абзац и пункт списка — одна строка любой длины; текст по ширине не переносить. Новая строка — только новый абзац, пункт списка, заголовок, строка таблицы или код. Адрес места — `файл#раздел` или id, не номер строки.»

Не действует: код, сырые тексты-источники (`D:\kb\sources\*\raw\`), файлы, которые пишет только инструмент (`openspec/specs/**`, `.warrant/**`), архивы (`arhived/`, `openspec/changes/archive/**`).

Неверно:

```markdown
Цель — **v0.4 как одна согласованная архитектура**: все обоснованные предложения разбора внесены, спорные — решены
пользователем, ни одно не потеряно.
```

Верно:

```markdown
Цель — **v0.4 как одна согласованная архитектура**: все обоснованные предложения разбора внесены, спорные — решены пользователем, ни одно не потеряно.
```
