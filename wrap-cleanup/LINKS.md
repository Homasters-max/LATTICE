# Правило ссылок

Ссылка ведёт на то, что агент находит одним поиском — id или заголовок; номер строки не используется никогда.

## Почему

- Номер строки меняется при любой правке выше по файлу: ссылка молча начинает указывать не туда (51 такой адрес пришлось чинить в LATTICE после склейки переносов).
- Id и заголовок не зависят от положения в файле: агент переходит одним Grep по файлу и получает точную строку, без пересчёта и без чтения файла целиком.

## Правило

Ссылка — на самую точную цель из существующих, сверху вниз:

| Цель | Форма ссылки | Переход агента |
|---|---|---|
| объект с id: объект `dev/`, заметка базы, ADR, Change | `ISS-018`, `RUL-012`, `kb/PAT-195`, `warrant/ADR-0042`, `lattice/pin-v0-8-1` | Grep `^id: ISS-018` по папке типа; заметка базы — `kb-search --section PAT-195` |
| элемент документа с id: инвариант, решение, требование, сценарий, вопрос | `design/domains/10-kernel.md#KR-12`, `lattice/pin-v0-8-1#I-4`, `kb/PAT-195#Решение` | Grep id в файле → строка, которая начинается с id |
| раздел | `design/domains/10-kernel.md#4. Идентификаторы` | Grep `^#+ 4. Идентификаторы$` в файле → читать с этой строки до следующего заголовка того же уровня |
| файл целиком | `design/05-slices.md` | Read |

Как писать:

- Номер строки (`файл.md:42`, `:42-50`) и отпечаток (`#a1b2c3`) — не писать.
- Путь — от корня репозитория; внутри того же файла — только `#KR-12` или `#4. Идентификаторы`. Другой проект или база знаний — через пространство: `kb/…`, `warrant/…`.
- Заголовок — дословно, как в файле, с номером, без `#` и выделения. Id — с тем же регистром, что в определении (`#S1`, не `#s1`).
- Заметка базы знаний — `kb/<id заметки>` или `kb/<id>#<раздел>`, не путь к файлу базы: путь `patterns/pat-195-….md` относителен базе, из другого проекта по нему файл не найти.
- Id элемента объявляется в начале строки, где он определён: первая ячейка таблицы `| KR-12 |`, пункт `- **KR-12** …` или заголовок `### KR-12. …`. Так поиск отличает определение от упоминаний.
- Нужно сослаться на утверждение, у которого нет id, и заголовок для этого слишком крупный — дать утверждению id в самом документе (строкой в таблице инвариантов или решений), а не ссылаться на строку или абзац.

## Проверка

Ссылка `файл.md#X` верна, если в файле есть заголовок `X` или строка, которая начинается с id `X`; `kb/ID#X` — если в базе есть заметка с `id: ID` и в ней заголовок `X`. Команда: `node C:/Users/Xiaomi/.claude/tools/md-wrap/md-wrap.mjs --links <пути>` — битые ссылки (класс S) с файлом и строкой. Переименовал заголовок или id — исправь ссылки на него в том же коммите.
