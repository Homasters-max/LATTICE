# ADR-27. Область уникальности зерна — пространство автора; `grain_scope: store` для справочников `std`

Статус: принято 2026-09-27 · сессия R3

Ключ зерна уникален среди живых сущностей типа **в пространстве имён автора**: индекс `grain` — по `(namespace, тип, hash)`. Тип может объявить `grain_scope: store` — одна сущность на всё хранилище (справочники пространства `std`: единицы). Домен (`std/domain`) — группа блоков проекта: область — пространство, поля `project` нет (уточнено в D03, Q1). Формула ключа (`hash(id типа, значения измерений)`, T-11) не меняется — меняется ключ индекса и область правила `grain-unique`. `grain_scope` — поле `core/type`, владелец — 11-identity-grain.

**Варианты:** область — всё хранилище для всех типов (v0.3): чужое пространство занимает ключ и блокирует запись владельца; разрешение требует прав на чужие сущности. Область — проект: дублирует пространство имён (N-11, измерение `project` в `std/domain`).

**Последствия:** 11-identity-grain (зерно, `grain-unique`; И-2; `std/domain` без `project` — D03), 12-ledger (индекс `grain`), 10-kernel (таблица `core/type` — `grain_scope`), 13-rules (`grain-unique`), 02-glossary (T26). Откат высокий: меняет область проверки задним числом; до S2.

**Опора:** Q-15 C-3, D-32; T-7, T-8.

**Реестр:** ADR-27 (решить здесь: 11-identity-grain/И-2).
