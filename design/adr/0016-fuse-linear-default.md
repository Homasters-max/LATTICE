# ADR-16. Слияние judge и BM25 — `linear` до стенда; порог — по judge

Статус: принято 2026-09-27 · сессия R6

База знаний молчит о выборе между `linear` и `rrf`; решает стенд. До него стадия `fuse` работает в режиме `linear` (judge + 0,3 · bm25/max), порог стадии `threshold` читает балл judge (ADR-13, 20-lens/И-4) при любом режиме слияния — `fused` задаёт только порядок. `rrf` — кандидат регрессионного сравнения на стенде (S9).

**Варианты:** `rrf` по умолчанию — сравнения в базе нет (D-56), проверка запланирована стендом (`design/01-first-run.md:68`, `design/05-slices.md:16`); порог по judge делает выбор режима независимым от порога.

**Последствия:** 20-lens (стадия `fuse`, `threshold`), 23-bench (сравнение `linear`/`rrf` в S9). Откат низкий — режим стадии в ревизии конвейера.

**Опора:** Q-52 C-1, D-56; ADR-13.

**Реестр:** ADR-16.
