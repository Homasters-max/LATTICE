# ADR-5. «Последнее утверждение» выбирает 14-trust; утверждения копятся; поле `via`

Статус: принято 2026-09-27 · сессия R2

Утверждения (`core/assert`) копятся, как сейчас: `key` пуст, ядро «текущее» для них не считает. Свёртку делает 14-trust: учёт — по `via ?? by`; для владельца пространства цели и допущенного декларанта действует последнее утверждение **участника** по цели, для остальных — последнее утверждение **сессии**. В теле `core/assert` — необязательное поле `via`: исходная сессия (вердикта, потребителя), когда утверждение пишет посредник (сессия `learn`). В 10-kernel §7 — явное исключение: «утверждения копятся; текущее выбирает 14-trust».

**Варианты:** (а) `key` `core/assert` включает автора (сессию или участника) — «текущее» считает общий механизм ядра; верно, если появятся другие виды фактов «по автору», но вводит автора в ключ, чего ADR-6 не делает, и растит ядро. Переход (б)→(а) — новая версия `core/assert` и пересборка индекса; журнал при обоих одинаков.

**Последствия:** 10-kernel (§7 исключение), 14-trust (§2 правило «последнее», TR-02, `via`; И-7, И-12), 22-run (обучение пишет утверждения с `via`), 02-glossary (T120). Независимость подтверждений — ADR-26.

**Опора:** Q-13 C-3, Q-36 C-2, Q-38 C-2, D-24, D-50, D-52; П-7; T-1, T-15.

**Реестр:** ADR-5, П-7; определяет 14-trust/И-7, И-12.
