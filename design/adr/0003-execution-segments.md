# ADR-3. События исполнения со сроком — сегменты одного журнала

Статус: принято 2026-09-27 · сессия R1

События исполнения (`std/measurement`, `std/execution` и подобные) пишутся в тот же журнал, но в сегменты со сроком
хранения по типу; срок = горизонт replay. Проекции (индекс) сегменты не читают. Принцип «строка журнала не меняется»
(LG-01, KR-14) получает одно явное исключение: **сегмент истекает только целиком**, строка внутри — никогда.

**Варианты:** (б) хранилище телеметрии вне журнала — отвергнуто: ломает LG-08 (всё, что влияет на результат, —
в журнале) и replay по событиям исполнения.
**Последствия:** 10-kernel (KR-14, И-19), 12-ledger (инварианты append-only, LG-01 — исключение «сегмент целиком»),
22-run (RN-06, И-17). Где задан срок по типу — решает D01/D05; рекомендация — таблица в 12-ledger, не поле
`core/type` (поле расширило бы ядро, T-10). Откат высокий: переход к (б) обрывает replay по старым сегментам.
**Опора:** Q-09 C-2, Q-28 C-3, D-2, D-31; T-12.
**Реестр:** ADR-3; определяет 10-kernel/И-19 (= 12-ledger/И-18), 22-run/И-17.
