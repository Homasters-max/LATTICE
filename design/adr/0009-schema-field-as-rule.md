# ADR-9. Схема тела — поле `schema` в `core/type`, компилируется в правило с уровнем

Статус: принято 2026-09-27 · сессия R3 · уточнено C2a

Форма тела объявляется полем `schema` типа (подмножество JSON Schema, без `$ref` — R1 Q4.3). Поле — сахар: ядро компилирует его в правило с примитивом `schema` и уровнем (`hard` / `soft`); уровень задаётся в поле, по умолчанию `hard` для `core` и `std`. Уровень в поле — опора лестницы «нет схемы → `soft` → `hard` новой версией типа» (13-rules/И-3, T-13). Поле уже есть в `core/type` — генезис не меняется, меняется смысл (форма с уровнем).

**Варианты:** (Б) схема — только через `rules`: один путь, но самая частая проверка требует отдельного объекта-правила на каждый тип, и уровень схемы не виден в типе.

**Последствия:** 10-kernel (таблица полей `core/type`, `schema`; И-1), 13-rules (примитив `schema`, RL-02, лестница; И-3), 02-glossary. Откат низкий до S2.

**Опора:** Q-30 C-2, D-45; T-13.

**Уточнено C2a:** у общих типов (`core`, `std`, импортируемые, T172) схема обязательна, закрыта и `hard` — это обязательство, не умолчание (RL-02); уровень в поле выбирает только проектный тип (лестница). Реестр: N-118, N-119.

**Реестр:** ADR-9; частично — 10-kernel/И-1, 13-rules/И-3 (обязательность, закрытость, лестница — пакет T-13).
