# ADR-13. Балл решает только обратимое действие, ошибку которого ловит вердикт

Статус: принято 2026-09-27 · сессия R5

Балл judge — ранжирование, не разрешение (TR-06, P5). Действие по баллу без участника допустимо только при двух условиях сразу: действие обратимо и дёшево, и его ошибку ловит последующий вердикт (потребителя или стенда). Всё остальное решает правило, владелец или вердикт. Названное исключение — повтор решения (`recall`, `design/domains/14-trust.md:83`): выдача без поиска, с полями `by: exact / judge / composer` и баллом `p`; доля серой зоны — в отчёте стенда. Порог читает `max(scores.judge)` закреплённой версии judge, не `fused` (`fused` — только порядок, не [0,1]); вероятность — только после калибровки на `dev` по обеим ошибкам (T-14). «Почему» TR-06: закон Гудхарта, баллы разных версий несравнимы, «может ≠ имеет право».

**Варианты:** (А) точечные исключения по каждому месту — правило не проверяется при новом месте, где балл решает; (В) грант на операции по баллу — вводит в `core/grant` вероятностное право, смешивает доверие и допуск (TR-06).

**Последствия:** 14-trust (TR-06 «Почему», §повтор решения — `recall.by`, `p`), 20-lens (`threshold` по `max(scores.judge)`), 21-compose (`recall`), 11-identity-grain (кандидаты по баллу — `std/alias-candidate`, ADR-8, в силу не входят), 23-bench (доля серой зоны), 02-glossary (T89). Привязка порога к версии judge — сессия R5, раунд 2. Откат средний; общее правило (14-trust/И-17) — высокий.

**Опора:** Q-40 C-1, C-2, C-3, D-54; T-14.
