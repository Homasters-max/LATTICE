# ADR-19. Граница коммита вызова — один коммит на вызов

Статус: принято 2026-09-27 · сессия R1 · уточнено D12 Q2, C2a

Для первого запуска вызов пишет результат одним коммитом (граница — T-9: `append(rows, expect)` + маркер `core/commit`) при условии «вызов короткий, без `exec`». `materialize` — в двух режимах (22-run/Р-2 Б). Режим агента не ждёт ответа в процессе: агент отвечает командой `lattice answer <run> <json>`, ответ ложится в кэш composer, вызов перезапускается и берёт его из кэша.

**Варианты:** (б) вызов пишет частями, видимость — завершающим фактом, checkpoint (12-ledger/И-8) — не сейчас: верен для долгих вызовов и `exec`, для коротких — лишний механизм. **Триггер перехода на (б):** появился `exec` или вызовы дольше нескольких минут. Переход дешёвый: маркер уже в формате (T-11), старые вызовы остаются валидны, (б) добавит завершающий факт и фильтр.

**Последствия:** 22-run (RN-03 вариант (а), И-5, И-6 `materialize`), 21-compose (И-6), 12-ledger (И-8 — отложено с триггером), 30-adapters (И-6 — порт `composer` и `lattice answer`, волна 3 / R5).

**Опора:** Q-23 C-2 (уверенность средняя), Q-65 C-1, Q-65 C-2, Q-77 C-2, D-6, D-73, D-85; Ф-4; T-9.

**Уточнено D12 Q2 (AD-09), записано C2a:** ответ агента хост дописывает в файл `.lattice/answers/<execution>.jsonl` (команда `lattice answer <execution> <json|@файл>`); кэша у `composer-caller` нет. Истина — `calls` трассы `std/execution`, файл ответов — нет (`design/domains/30-adapters.md` §5). Реестр: N-112.

**Реестр:** ADR-19; определяет 22-run/И-5, И-6; откладывает 12-ledger/И-8.
