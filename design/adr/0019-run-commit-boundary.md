# ADR-19. Граница коммита прогона — один коммит на прогон

Статус: принято 2026-09-27 · сессия R1

Для первого запуска прогон пишет результат одним коммитом (граница — T-9: `append(rows, expect)` + маркер
`core/commit`) при условии «прогон короткий, без `exec`». `materialize` — в двух режимах (22-run/Р-2 Б). Режим агента
не ждёт ответа в процессе: агент отвечает командой `lattice answer <run> <json>`, ответ ложится в кэш composer,
прогон перезапускается и берёт его из кэша.

**Варианты:** (б) прогон пишет частями, видимость — завершающим фактом, checkpoint (12-ledger/И-8) — не сейчас:
верен для долгих прогонов и `exec`, для коротких — лишний механизм. **Триггер перехода на (б):** появился `exec` или
прогоны дольше нескольких минут. Переход дешёвый: маркер уже в формате (T-11), старые прогоны остаются валидны,
(б) добавит завершающий факт и фильтр.
**Последствия:** 22-run (RN-03 вариант (а), И-5, И-6 `materialize`), 21-compose (И-6), 12-ledger (И-8 — отложено с
триггером), 30-adapters (И-6 — порт `composer` и `lattice answer`, волна 3 / R5).
**Опора:** Q-23 C-2 (уверенность средняя), Q-65 C-1, Q-65 C-2, Q-77 C-2, D-6, D-73, D-85; Ф-4; T-9.
**Реестр:** ADR-19; определяет 22-run/И-5, И-6; откладывает 12-ledger/И-8.
