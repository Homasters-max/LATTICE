# ADR-31. Коммит атомарен целиком — CAS по хвосту журнала

Статус: принято 2026-09-27 · сессия C2a

Шаги 0–5 коммита (ключ идемпотентности, `grain-unique`, `count`, `unique-within`, `expect`) считаются по индексу вне
замка адаптера; атомарны только `append` и `expect`, а `expect` не видит создаваемых сущностей — гонку двух `ensure`
одного ключа зерна и двух коммитов с одним `key` ничто не ловит (C1 B7, E28). Решили: **оптимистичный CAS по
хвосту**. `append(rows, expect?, tail)` — адаптер под своим замком сверяет последний `seq` журнала с `tail`, на
котором посчитаны шаги 0–5; не совпало — отказ `conflict`, `commit` дочитывает индекс `scan(tail + 1)` и повторяет
шаги 0–5 (до 3 раз, затем `conflict` вызывающему). Порт остаётся без `lock()` (T-9). Занятый замок — ожидание со
сроком, затем отказ `locked`.

**Варианты:** (б) `lock()` в порте, `commit` держит замок на шагах 0–6 — отменяет T-9 «порт без `lock()`»; (в) узкий
CAS — только ключ зерна и ключ идемпотентности в `append`: гонки `count`, `unique-within` остаются.
**Последствия:** 12-ledger (§2 шаги коммита, §5 контракт `Store` — `tail`, `locked`; выход `commit`), 11-identity-grain
(гонка `ensure` — ссылкой сюда), 22-run (таблица «Сбой → что пишется» — `locked`), 30-adapters (`store-jsonl`, замок).
Откат средний: контракт `Store` и контрактные тесты.
**Опора:** T-9; C1 B7, E28, E29 (`integration/audit/README.md`).
**Реестр:** N-78, N-110, N-111.
