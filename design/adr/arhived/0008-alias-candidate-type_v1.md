# ADR-8. Кандидат в алиас — отдельный тип `std/alias-candidate`; `core/alias` — только подтверждение владельца

Статус: принято 2026-09-27 · сессия R3 · уточнено C2b

Предложение «A — это, возможно, B» (LENS, импорт, обучение) пишется фактом `std/alias-candidate` с ключом
`[alias, canonical]`: `writers` — любой (`any`), в силу не входит. **Уточнено C2b (1·Q3, 2·Q4):** «накопительный» —
только пустой `key`; у кандидата ключ есть — следующий писатель той же пары обновляет балл; `value: {p}`; кандидат
открыт, пока нет `core/alias` в силе и `std/distinct {value: true}`; один порог `candidates.min_p` для сущностей и
потребностей (11 §6, 21 §3). `core/alias` пишет только владелец
пространства цели или допущенный (ADR-6) — это подтверждение кандидата. Индексы `aliases`, `grain` и `resolve` видят
только `core/alias` в силе. Один механизм — для сущностей и для потребностей (Ф-2). Кандидат того же типа больше не
снимает действующий алиас (П-13). Пороги кандидатов и разбиение потребностей — тема T-8, сессия R6.

**Варианты:** (б) `core/alias` с ключом `[alias, canonical]` + hard «один действующий»: меняет форму записи
управляющего факта и требует расширить его `writers` до агентов LENS — против ADR-6.
**Последствия:** 11-identity-grain (алиасы, GR-05, GR-06, `resolve`; И-12), 14-trust (в силу при `declared` — через
подтверждение), 21-compose (кандидат потребности; И-2, И-6 — R6), 30-adapters (алиасы LLM при импорте — кандидаты),
01-first-run, 12-ledger (индексы), 02-glossary (T28, T30, T123). Откат низкий.
**Опора:** Q-19 C-3 (уверенность высокая), D-36; П-13; Ф-2; T-8; ADR-6.
**Реестр:** ADR-8, П-13, Ф-2; определяет 11-identity-grain/И-12.
