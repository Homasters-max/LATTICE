# ADR-26. Группа независимости подтверждений: участник для `human`/`machine`, `(kind, model)` для `agent`

Статус: принято 2026-09-27 · сессия R2

Независимость подтверждений считается не по сессиям, а по **группам**: `human` и `machine` — по участнику
(`actor`), `agent` — по паре `(kind, model)`. `observed` — «+» от ≥ `observe_groups` разных групп, из них ≥ 1 не
из группы автора. `actor.model` у агента обязателен; детализацию `model` задаёт владелец в реестре участников (ADR-25:
`core/actor` пишет владелец). Рекомендация grilling 2 «разные сессии одного агента независимы» заменяется: «разные
сессии одной группы независимости не увеличивают». Сессия остаётся единицей «последнего утверждения» (ADR-5).

**Варианты:** (б) по сессиям, как TR-03 v0.3: подтверждения разных сессий одной модели на том же evidence и промпте
коррелированы, но считаются двумя «да». (в) По участнику для всех: два агента одной модели, заведённые разными
участниками, — снова два «да».
**Последствия:** 14-trust (§2 `observed`, §1 `actor.model`, TR-03; И-8, И-6 — `settled` считается в группах), 20-lens
(`std/cue` — подтверждение), 22-run (обучение, И-11, И-14, И-15 — R6), 23-bench (И-10 — R6), 05-slices (S3:
`observed` — от разных групп), 01-first-run (E3: три сессии simulate-consumer одного агента — одна группа, `observed`
не достигается; ожидания сверяет D11 — **заменено D11**: k симуляторов `machine` — k групп, окно удаления замыкается
при k ≥ `removal_window.n`, отрицательный контроль — те же вердикты одной группы; `design/05-slices.md` S8, C2a), 02-glossary (T53, T55, T121). Откат необратим: ключ входит в пересчёт доверия
всех целей. Уверенность в выборе ключа — средняя (перепроверка итогов).
