# ADR-18. Графы способностей: цепочка стадий и граф решения — разные модели на v1

Статус: принято 2026-09-27 · сессия R5

Конвейер v1 — линейная цепочка стадий; её проверяет `contract` (13-rules §3: чтения записаны раньше, T-3).
Решение-граф (`form: graph`, ADR-17) — связи `std/link` между членами; v1 проверяет на нём примитив `acyclic` (13-rules
§2, `design/domains/13-rules.md:43`). Snapshot
решения не является телом составной способности. CP-04 (`design/domains/21-compose.md:102`) — без «одна модель».
DAG-конвейер — новой версией интерпретатора (10-kernel/И-31).

**Варианты:** (a) snapshot решения = тело составной способности, одна модель — связывает формат решения с форматом
конвейера до появления DAG-конвейера; пересмотр — вместе с ним.
**Последствия:** 21-compose (CP-04), 13-rules (§3 `contract` — для цепочки, `acyclic` — для решения), 22-run (формат конвейера). Откат средний.
**Опора:** Q-59 C-2, D-71.
**Реестр:** ADR-18.
