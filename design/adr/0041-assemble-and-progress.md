# ADR-41. Корень сборки с фазами, порт хода `Progress`, результат вызова `pack | pending`

Статус: принято 2026-09-29 · сессия R1–R4 (архитектурный разбор 2026-09-29, кандидат 4)

Скелет S0 не собирался по описанным интерфейсам: 04 §6 подключал фиктивные адаптеры проводкой, а ADR-28 и AR-09 — через `setup.ports` в журнале; `lattice init` писал `<пространство>/setup@1` без выбора фиктивных. Проверки проводки шли двумя заходами без имён: отказ «у адаптера из `setup.ports` нет привязки» возможен только после открытия хранилища. Run писал и читал `.lattice/runs/<id>.log`, старил его по `pending_ttl` хоста и брал `env` процесса — ввод-вывод вне `adapters/` и `cli/` без порта. `Stage → Promise<Ctx>`, а `Composer.run` может вернуть `{pending}`; `run()` описан как `→ pack`.

Решили:

1. **`assemble(config, env, store) → {deps, refusals}`** — корень сборки с названными фазами отказов: схема проводки → открытие хранилища → `setup` из журнала → привязки адаптеров `setup.ports`. Отказ несёт фазу и путь поля; таблица отказов S0 тестируется через `assemble`.
2. **Фиктивные адаптеры — тем же путём, что живые:** через `setup.ports` (ADR-28); 04 §6 выравнивается. Фиктивная `setup` для `init` — семя тестов и `lattice init --setup <файл>`.
3. **Порт хода `Progress`** (`begin`, `step`, `park`, `abandoned`, `end`) — контракт у run, адаптеры `progress-fs` (`.lattice/runs/`) и `progress-memory`; брошенный `pending` (RN-37) — на фиксированных часах, без файловой системы.
4. **`run() → {pack} | {pending, task}`**; стадия может вернуть `{pending}` — сигнатура стадии это называет. `env` (ADR-36) передаёт корень сборки, не читает процесс.
5. **Ответ агента привязан к кортежу.** Файл хода запоминает кортеж исполнения на `pending`; перезапуск с другим кортежем (новая ревизия `setup`, промпт) сбрасывает записанные ответы — задание уходит заново; ответ ключуется `(kind, prompt_hash, хэш входа)`. Фикстуры `composer-fixture` ключуются видом и смысловым ключом задания (потребность, id кандидатов), не хэшем промпта — правка сборки промпта их не ломает.

**Варианты:** (б) оставить `wire.ts` без фаз и файл хода в run — тест структуры требует исключения для run, `pending` не проверить без диска.
