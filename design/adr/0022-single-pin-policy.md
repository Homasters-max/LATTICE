# ADR-22. Одна политика проверки смены настройки — до живого трафика

Статус: принято 2026-09-27 · сессия R6

Итоги предлагали полосы по риску: полный `test` для смены конвейера и облегчённый `dev` для смены параметров. До живого трафика риск смены не измерить, поэтому любая смена `std/setup`, чьи вердикты должны обучать систему (гейт ADR-29), проходит один путь — прогон по регрессионному плану владельца на `test`. Поэтапная раскатка и автооткат — вне объёма v0.4 (23-bench/И-17); пересмотр — с живым трафиком.

**Варианты:** полоса `dev` для параметров — граница «параметр / конвейер» не определена, а смена порога меняет вердикты так же, как смена стадии (довод агента).

**Последствия:** 23-bench (регрессия, «Вне объёма»), 22-run (гейт ADR-29 читает `pass` одного вида). Откат низкий.

**Опора:** Q-74 C-4.

**Реестр:** ADR-22, 23-bench/И-17.
