# ADR-45. Калибровка — одно значение `CalibratedThreshold`; оценщик пула — шов `Scorer`; LENS одной стадией — отложено

Статус: принято 2026-09-29 · сессия R1–R4 (архитектурный разбор 2026-09-29, кандидат 8, частично); код — срез S5

`calibrated_for` жил в трёх местах (`threshold`, `recall`, `candidates` в политике) с тремя поведениями (отказ на старте, запись с пометкой, `null` — «не откалиброван»); интерпретатор знал имена стадий (`threshold` → промпт `score`, `recall` → промпт `verify`); у порогов `route` и повторного `verify` в self-search калибровки не было. Кто превращает баллы пула в `candidates`, не сказано (неявно `fuse`). Отчёт предлагал ещё свести 11 стадий LENS в одну стадию `retrieve` — это огрубляет LN-03 («стадия = единица способности»).

Решили:

1. **`CalibratedThreshold {value, calibrated_for: {adapter, model, prompt_hash, bench} | null, call: score | verify | choose, onMismatch: refuse | mark}`** — одно значение калиброванного порога; поле привязки сохраняет имя `calibrated_for` (T136; уточнено D05 — имя уже в восьми файлах). Способность объявляет свои калиброванные параметры в контракте; run сверяет их с `setup` обобщённо, не по именам стадий. `calibrated_for: null` — «не откалиброван»: поведение без калибровки задаёт стадия (LN-07, CP-05).
2. **Шов `Scorer`:** оценщик пула `pool → Record<Id, number>`; адаптеры шва — `bm25`, `judge` (эмбеддинги — позже). Слияние баллов в `candidates` — стадия `fuse` явно.
3. **Отложено — LENS одной стадией `retrieve`:** вопрос в 20-lens с рекомендацией; триггер — код S5 (тесты стадий требуют ручной сборки большого частичного `Ctx`).

**Варианты:** (а) принять кандидат целиком — гранулярность самоописания конвейера данными теряется до кода; (в) отложить всё — три поведения калибровки расходятся уже сейчас.

**Последствия:** 20-lens (§4 — `threshold`, `fuse`, `Scorer`; «Вопросы для grilling» — `retrieve`), 13-rules (§3 — калиброванные параметры способности), 21-compose (§3 — `recall`), 22-run (§3 — обобщённая сверка, RN-10, RN-35), 14-trust (§4 — `candidates.calibrated_for` той же формы).

**Опора:** архитектурный разбор 2026-09-29, кандидат 8; ADR-13, ADR-16 — не пересматриваются; решение maintainer'а (сессия R1–R4, Q11, вариант (б)).
