# ADR-23. Пересмотр хранилища — по времени пересборки p95

Статус: принято 2026-09-27 · сессия R6

Граница «< 50 МБ» (`design/domains/12-ledger.md:109`) — эвристика без замера, не измеримый триггер (12-ledger/И-1). Триггер пересмотра хранилища (`store-jsonl` → SQLite) — время пересборки индексов, p95; число порога и условие перехода на SQLite задаются замером после первого запуска.

**Варианты:** Б задержка чтения p95, В объём журнала с замером порога — отчёт метрику не выбирает, только требует «измеримо»; А взята потому, что прямо задаёт ощутимую задержку старта и переключения хранилища (фрагмент 12-ledger Р-1).

**Последствия:** 12-ledger (`:109` — триггер), 30-adapters (условие перехода `store-jsonl` → SQLite), 01-first-run (замер). Откат низкий.

**Опора:** Q-21 C-2, Q-80 C-3, D-4, D-88.

**Реестр:** ADR-23, 12-ledger/И-1, 30-adapters/И-12, Ф-9.
