# LATTICE — проект системы (design, v0.4)

Универсальная независимая система: **память проверенных блоков** (знания и способности) и **поиск подходящих блоков
под задачу**, из которых LLM собирает решение, а система учится на результате. Работает в нескольких проектах;
первый стенд — подбор норм для агентов WARRANT.

Источники: концепция — `../LATTICE-v0.2-*.md`; детали — черновики `../2026-09-26-*` (история, не норма). Где этот
каталог расходится с черновиками — действует этот каталог.

## Конвенции

- Шаблон домена: Назначение → Модель → Операции → Инварианты → Решения → Вопросы для grilling → Вне объёма.
- Решение — строка с ID (`KR-03`, `GR-02` …): на него ссылаются grilling и код. Изменённое в v0.4 — в «Почему»
  опора `v0.4 · ADR-n · Q-NN C-n`.
- Решение шире одного домена и смена принципа [00-vision](00-vision.md) — только через ADR ([adr/](adr/README.md)).
- Вопрос для grilling — всегда с рекомендацией; принятое переезжает в «Решения».
- Текст — русский; коды, поля, ID — английские.
- Всё машинное — JSON (канонический, [10](domains/10-kernel.md) KR-06).
