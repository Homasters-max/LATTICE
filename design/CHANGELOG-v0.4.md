# CHANGELOG — design v0.3 → v0.4

v0.4 вносит итоги архитектурного разбора (`research/analysis/arch-changes.md`: сквозные темы T-1…T-16, развилки,
противоречия П-n и Ф-n) и принятые предложения PF-01…PF-06. Решения приняты через grilling: сессии S0, R1–R6,
D01–D14, аудит C1, сверка C2a–C2c, финальное чтение F (журналы — `integration/sessions/`, реестр внедрения — `integration/ledger.md`).
Базовая линия — тег `design-v0.3`.

**Коротко.** 33 ADR, все приняты ([adr/](adr/README.md)). Решений в «Решениях» доменов и обзорных файлов было 97,
стало 194: 97 новых, ни одно не удалено, почти все старые уточнены (в «Почему» — опора `v0.4 · ADR-n · …`).
Терминов глоссария было 112, стало 176, удалённых нет. Появились карта владения ([04](04-architecture.md) §8) и
спецификация срезов «Готово, когда» ([05](05-slices.md)).

## Сквозное

- **Порты** — контракт у домена-потребителя (ADR-24); `30-adapters` — только реализации, корень сборки, хост, CLI.
- **Участник и сессия** — реестр участников `core/actor`; декларант — только `human`; сессию открывает и пишет хост
  (ADR-25). Независимость — по группам (ADR-26).
- **Права на факты** — `writers`, `inForce` и роль цели `target` в типе факта; «текущий» — последний по `seq` среди
  допущенных (ADR-6).
- **Настройка исполнения** — объект `std/setup` (конвейер и модели портов) в журнале, проводка — в
  `lattice.config.json` (ADR-28, PF-01…06).
- **Граница вызова** — один коммит на вызов; события исполнения — в сегментах со сроком (ADR-19, ADR-3).
- **Гейт обучения** — hard-примитив `learning-gate` на фактах обучения (ADR-29).
- **Периметр ядра** — замороженное ядро (версией ядра) и код системы (релизами) (ADR-30, ADR-32; перечень —
  [04](04-architecture.md) §1).

## По доменам

### [10-kernel](domains/10-kernel.md) — 14 → 18 решений

- Каноническая форма — JCS целиком, NFC на входе, тестовые векторы формата v1 (KR-06, ADR-1); то же тело под
  `type@n+1` — новая ревизия (KR-03, ADR-2).
- Факт: `writers` (`owner` ⊂ `grant` ⊂ `any`), `inForce`, `target`, ключ; окончание — только `value: false`
  (KR-13, ADR-6). `extends` наследует контракт с `key` только сужением (KR-09, ADR-12).
- `core/holds` — значение, которое пространство ещё не держит (KR-15); генезис из кода, хэш — константа версии
  (KR-16); `by` — сессия (KR-17); порядок — только `seq` (KR-18).
- Удаления нет; сегменты исполнения истекают целиком — закреплённая ссылка туда отвечает `expired` (KR-14, ADR-3).

### [11-identity-grain](domains/11-identity-grain.md) — 7 → 15

- Область зерна — пространство автора, `grain_scope: store` — для справочников `std` (GR-02, ADR-27); смена зерна
  `std`-типа — по пространствам с планами владельцев (GR-14, ADR-7).
- Семантические дубли — только кандидаты `std/alias-candidate`, `core/alias` — подтверждение владельца (GR-06, ADR-8);
  отказ — `std/distinct` (GR-12).
- `ensure` не меняет найденное, гонка — CAS по хвосту (GR-11, ADR-31); слияние — в одном пространстве (GR-10).

### [12-ledger](domains/12-ledger.md) — 8 → 18

- Маркер коммита `core/commit`, заголовок строки `seq`/`commit`/`kernel`/`key` (LG-12); ключ идемпотентности —
  раздел индекса `keys` (LG-13).
- Коммит атомарен целиком: CAS по хвосту, `locked` (LG-17, ADR-31); секреты — отказ коммита, PII — допущение (LG-16).
- Сегменты со сроком и раздел `executions` для проверок коммита (LG-15, LG-18, ADR-3); хранилище на проект, `std` и
  импорт — копии строк (LG-11, ADR-4); триггер пересмотра хранилища — p95 пересборки (LG-09, ADR-23).
- Порт `Store`: вход коммита — `Draft`, хранимая строка — `Row`; порты `clock`, `ids` (LG-05).

### [13-rules](domains/13-rules.md) — 6 → 15

### [14-trust](domains/14-trust.md) — 7 → 12

## Отменено из v0.3

- Свой порядок ключей канонической формы → JCS (ADR-1).
- Все контракты портов в `30-adapters` → у потребителя (ADR-24).
- Независимость по сессиям (TR-03 v0.3) → по группам (ADR-26).
- Область зерна — всё хранилище → пространство автора (ADR-27).
- P9 «себя не описывает только малое ядро» → ядро и код системы (ADR-30).
- Пошаговая запись прогона → один коммит на вызов (ADR-19); прогон частями отложен с триггером.
- CP-04 «одна модель графа» → две модели (ADR-18).
- Блок — наследник типа-основы блока (T66 v0.3) → признак: у типа есть `card` (T66).
- LLM-`summary` в теле ревизии блока → отдельный факт автора `agent` (TR-09).

Отклонены при внедрении (реестр, вердикт `отклонить`): hard-правило «чувствительные поля — только в своих
сущностях» (10-kernel/И-20), омоним T55 (снят переименованием `basis`).
